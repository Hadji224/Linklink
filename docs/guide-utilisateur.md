# Guide utilisateur

## Se connecter
1. Ouvrez l'adresse de LinkLink dans le navigateur de votre téléphone ou ordinateur.
2. **Première fois** : « Pas encore de compte ? J'ai un code d'invitation », puis saisissez votre nom, e-mail, mot de passe (8 caractères minimum), le code reçu et cochez l'acceptation des conditions.
3. **Installer sur le téléphone** : menu du navigateur → « Ajouter à l'écran d'accueil ».

## Accès et fonctions
| Accès | Peut faire |
| --- | --- |
| **Administrateur technique** | Exploiter la plateforme : comptes, sauvegardes, sécurité, transfert d'administration. Ne décide ni des dépenses ni des publications (sauf s'il tient une fonction, comme le PDG de démarrage). |
| **Fondateur** | Voir tous les projets, gérer ses tâches et fichiers, inviter. Peut tenir une ou plusieurs **fonctions** attribuées par le PDG. |
| **Invité** | Voir uniquement les projets où il est ajouté ; créer des tâches, déposer des fichiers, écrire des messages. |

| Fonction | Rôle |
| --- | --- |
| **PDG** | Attribue les fonctions et mandats, approuve les dépenses, confirme les archivages, règle les relances. |
| **Coordinateur** | Crée des projets, propose des membres et des responsables, coordonne les tâches. |
| **Chef de projet** | Responsable d'un projet : membres, tâches, déclaration de fin de projet. |
| **Chef d'infrastructures** | Dossier Infrastructure, journal de sécurité, exploitation technique sur mandat. |
| **Caissier** | Déclare les paiements des dépenses approuvées (jamais cumulé avec PDG). |
| **Chargé de communication** | Prépare et publie les communications validées, annonces. |

Les menus **Finances**, **Communications**, **Gouvernance** et **Journaux** apparaissent selon votre accès et vos fonctions.

## Finances
Faites une **Nouvelle demande** (bénéficiaire, montant, devise, motif). Le PDG approuve (un autre fondateur si le PDG est lui-même demandeur ou bénéficiaire) ; le Caissier déclare ensuite le paiement. Un montant payé différent du montant approuvé crée un **écart à régulariser** (accepter avec motif ou annuler). Modifier une demande déjà soumise invalide l'approbation.

## Communications
Rédigez un contenu (courant, projet, officiel, technique ou publicité payante) : il suit son circuit de validation, puis le Chargé de communication le publie. En urgence, la **communication de crise** est publiée tout de suite et revue sous 24 h. Toute modification après validation relance les validations.

## Gouvernance
- **Validations** : tout ce qui attend votre décision, avec relances automatiques (24 h, 48 h, 120 h).
- **Fonctions, mandats, absences** : le PDG attribue ; un mandat dure 180 jours au plus et se révoque.
- **Sécurité** : accès d'urgence (deux détenteurs), transfert d'administration, suspensions de compte.

## Accueil
Vos tâches du jour, vos prochains rendez-vous, vos messages non lus et quatre indicateurs (projets actifs, tâches terminées cette semaine, rendez-vous de la semaine, nouveaux fichiers).

## Projets
- **Nouveau projet** (PDG ou Coordinateur) : nom, description, couleur, responsable (un fondateur ayant la fonction Chef de projet ; sans responsable, le projet est signalé « orphelin »). Ajoutez les membres dans l'onglet *Membres* (obligatoire pour qu'un invité le voie).
- La **progression** se calcule toute seule (tâches terminées / total).
- **Archiver, en deux temps** : le responsable **déclare le projet terminé** (en justifiant les tâches restées ouvertes), puis le **PDG confirme** (ou refuse avec motif). Un projet archivé reste consultable mais n'est plus modifiable ; seul le PDG peut le rouvrir ou le supprimer.

## Tâches
- Quatre vues : **Kanban** (glissez les cartes, ou utilisez ◀ ▶), **Liste**, **Calendrier**, **Ma journée**.
- Ouvrez une tâche pour : modifier les champs, cocher les sous-tâches, joindre des fichiers, commenter. Tapez **@** pour mentionner quelqu'un : il est prévenu aussitôt.
- Vous êtes prévenu quand une tâche vous est assignée, la veille et le jour de l'échéance, et si elle est en retard.

## Messages
- **Salons** : `#général`, `#annonces` (lecture seule sauf PDG, Chargé de communication et administrateur technique) et un salon par projet.
- **Messages directs** : « Nouvelle conversation ». Seuls vous et votre interlocuteur les voient.
- Le trombone joint un fichier (rangé dans le dossier « Messages »). Sur ordinateur, Entrée envoie ; sur téléphone, Entrée va à la ligne.

## Documents
- Naviguez dans les dossiers (fil d'Ariane), créez des sous-dossiers, déposez des fichiers (25 Mo max : PDF, Word, Excel, PowerPoint, images, ZIP, vidéos légères, texte).
- **Niveau de confidentialité** à chaque dépôt :
  - *Public* : peut être diffusé à l'extérieur ;
  - *Interne* : réservé à l'équipe ;
  - *Confidentiel* : auteur, administrateur technique et membres du projet ;
  - *Strictement confidentiel* : auteur et administrateur technique seulement (stratégie, accès techniques, négociations).
- Recherche par nom, auteur, date ou niveau. Les images s'ouvrent en aperçu ; les autres fichiers se téléchargent.

## Rendez-vous
Créez un rendez-vous (équipe ou lié à un projet), répondez *Présent / Peut-être / Absent*, et ajoutez-le à votre agenda avec « + Agenda » (fichier `.ics`). Les rendez-vous passés sont repliés.

## Mon profil
Modifier nom et e-mail, activer ou couper les e-mails de notification, changer le mot de passe, **exporter mes données**, **supprimer mon compte**, se déconnecter.
