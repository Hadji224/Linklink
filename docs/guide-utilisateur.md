# Guide utilisateur

## Se connecter
1. Ouvrez l'adresse de LinkLink dans le navigateur de votre téléphone ou ordinateur.
2. **Première fois** : « Pas encore de compte ? J'ai un code d'invitation », puis saisissez votre nom, e-mail, mot de passe (8 caractères minimum), le code reçu et cochez l'acceptation des conditions.
3. **Installer sur le téléphone** : menu du navigateur → « Ajouter à l'écran d'accueil ».

## Les rôles
| Rôle | Peut faire |
| --- | --- |
| **Super Admin** | Tout : rôles, salons, suppression de projets, journal d'activité. |
| **Fondateur** | Créer des projets et des rendez-vous, inviter, gérer tâches et fichiers (supprimer les siens). |
| **Invité interne** | Voir uniquement les projets où il est ajouté ; créer des tâches, déposer des fichiers, écrire des messages. |

## Accueil
Vos tâches du jour, vos prochains rendez-vous, vos messages non lus et quatre indicateurs (projets actifs, tâches terminées cette semaine, rendez-vous de la semaine, nouveaux fichiers).

## Projets
- **Nouveau projet** : nom, description, couleur. Vous en devenez membre ; ajoutez les autres dans l'onglet *Membres* (obligatoire pour qu'un invité le voie).
- La **progression** se calcule toute seule (tâches terminées / total).
- **Archiver** : passez d'abord le projet à « Terminé », puis « Archivé ». Il reste consultable mais n'est plus modifiable. Désarchivez-le pour le rouvrir.

## Tâches
- Quatre vues : **Kanban** (glissez les cartes, ou utilisez ◀ ▶), **Liste**, **Calendrier**, **Ma journée**.
- Ouvrez une tâche pour : modifier les champs, cocher les sous-tâches, joindre des fichiers, commenter. Tapez **@** pour mentionner quelqu'un : il est prévenu aussitôt.
- Vous êtes prévenu quand une tâche vous est assignée, la veille et le jour de l'échéance, et si elle est en retard.

## Messages
- **Salons** : `#général`, `#annonces` (lecture seule sauf Super Admin) et un salon par projet.
- **Messages directs** : « Nouvelle conversation ». Seuls vous et votre interlocuteur les voient.
- Le trombone joint un fichier (rangé dans le dossier « Messages »). Sur ordinateur, Entrée envoie ; sur téléphone, Entrée va à la ligne.

## Documents
- Naviguez dans les dossiers (fil d'Ariane), créez des sous-dossiers, déposez des fichiers (25 Mo max : PDF, Word, Excel, PowerPoint, images, ZIP, vidéos légères, texte).
- **Niveau de confidentialité** à chaque dépôt :
  - *Public* : peut être diffusé à l'extérieur ;
  - *Interne* : réservé à l'équipe ;
  - *Confidentiel* : auteur, Super Admin et membres du projet ;
  - *Strictement confidentiel* : auteur et Super Admin seulement (stratégie, accès techniques, négociations).
- Recherche par nom, auteur, date ou niveau. Les images s'ouvrent en aperçu ; les autres fichiers se téléchargent.

## Rendez-vous
Créez un rendez-vous (équipe ou lié à un projet), répondez *Présent / Peut-être / Absent*, et ajoutez-le à votre agenda avec « + Agenda » (fichier `.ics`). Les rendez-vous passés sont repliés.

## Mon profil
Modifier nom et e-mail, activer ou couper les e-mails de notification, changer le mot de passe, **exporter mes données**, **supprimer mon compte**, se déconnecter.
